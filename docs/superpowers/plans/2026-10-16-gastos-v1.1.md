# Gastos.io v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add swipe-to-pick labels with color tint, an optional spoken/typed description, expense notes, five light/dark themes, and an About the dev section to Gastos.io.

**Architecture:** Extends the v1.0 single-module app. Room schema v2 adds `description` and `notes` to `expenses`; repositories, backup (schema 2) and exports carry them through. Themes become data (`ThemeId` + palettes) selected via `AppPrefs` and applied by `GastosTheme`. Voice input uses the system `RecognizerIntent` (no mic permission).

**Tech Stack:** unchanged from v1.0 (Kotlin 2.0.21, Compose BOM 2024.12.01, Room 2.6.1 + room-testing, DataStore, Glance, Robolectric). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-16-gastos-v1.1-design.md` (builds on `docs/superpowers/specs/2026-10-16-expenses-tracker-design.md`). Mockups: https://claude.ai/artifact/PdEAtjcQKDc1wNkXee5gP1

## Global Constraints

- **No Claude attribution** in commits, PRs, or files. Plain messages, local git identity.
- Adding an expense from Home/widget stays one tap, no confirm. Every other create/update/delete (incl. theme and voice-language changes) shows a confirm popup.
- Description: optional, trimmed, blank → null, max 60 chars. Notes: optional, trimmed, blank → null, max 1000 chars.
- Swipe order = Labels screen order (position), wraps both ways. Home starts on last-used label (shared with widget via `AppContainer.setLastLabel`).
- Themes: Classic (default), Sand, Nord, Mocha, Forest — each light + dark, following the phone. Hex values exactly as in the spec's table. Danger stays #C2412D light / #EF6B55 dark.
- Widget unchanged (no description, always dark).
- Voice: `RecognizerIntent.ACTION_RECOGNIZE_SPEECH`, free-form, `EXTRA_LANGUAGE` = `en-PH` (default) or `fil-PH`; result replaces box text; hide mic if no recognizer.
- Restore of v1 backups must keep working; DB upgrade v1→v2 must keep all data.
- versionName 1.1.0, versionCode 2, same release key.

## Review Focus

1. **Upgrade from v1.0** — an installed v1.0 DB opens under v1.1 with all rows intact and null description/notes. Pinned in Task 1 (migration test).
2. **Old backup restore** — a schemaVersion 1 JSON (no description/notes keys) restores fine. Pinned in Task 2.
3. **Swipe vs. tap** — numpad taps and text-box taps never change the label; only a clear horizontal drag does. Pinned in Task 5 (pure gesture-decision test).
4. **Long/odd text in exports** — notes with commas, quotes, newlines; description with `&<>`. Pinned in Task 2.
5. **Theme contrast** — every theme/mode keeps fg-on-bg and on-accent-on-accent ≥ 4.5:1. Pinned in Task 3.
