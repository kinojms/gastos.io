# Gastos.io v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add payment methods (swipe left/right with brand-color tint), swipe up/down labels, an optional typed/spoken description, expense notes, five light/dark themes, and About the dev to Gastos.io.

**Architecture:** Extends the v1.0 single-module app. Room schema v2 adds a `payment_methods` table plus `paymentMethodId`, `description`, `notes` on `expenses`; repositories, backup (schema 2), exports, lists, Month tab and widget carry them through. Themes become data (`ThemeId` + palettes) selected via `AppPrefs`. Voice uses the system `RecognizerIntent` (no mic permission).

**Tech Stack:** unchanged from v1.0 (Kotlin 2.0.21, Compose BOM 2024.12.01, Room 2.6.1 + room-testing, DataStore, Glance 1.1.1, Robolectric). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-16-gastos-v1.1-design.md` (builds on `docs/superpowers/specs/2026-10-16-expenses-tracker-design.md`). Mockups: https://claude.ai/artifact/PdEAtjcQKDc1wNkXee5gP1

## Global Constraints

- **No Claude attribution** in commits, PRs, or files. Plain messages, local git identity.
- Adding an expense from Home/widget stays one tap, no confirm. Every other create/update/delete (labels, payment methods, theme, voice language, edits) shows a confirm popup.
- Description: optional, trimmed, blank → null, max 60. Notes: optional, trimmed, blank → null, max 1000.
- Payment methods default, in order: Cash #77808B, GCash #007DFE, Maribank #FF6A13, BPI #A6192E, Maya #00B26B, BDO #0033A0. Delete = archive (hidden from swipes/pickers, history keeps the name). At least one active method. v1.0 expenses → Cash on upgrade.
- Home: left/right = payment method (screen tint = method color), up/down = label (text only). Both wrap, both follow their screen's order, both start on last-used (shared with widget).
- Export columns: Date, Time, Label, Payment, Description, Amount, Notes (Amount = column F).
- Themes: Classic (default), Sand, Nord, Mocha, Forest — light + dark each, follow phone; hex values exactly from the spec table; danger #C2412D / #EF6B55.
- Widget: adds payment ticker; still no description, always dark.
- Voice: `ACTION_RECOGNIZE_SPEECH`, free-form, `EXTRA_LANGUAGE` `en-PH` (default) or `fil-PH`; result replaces box text; hide mic if unavailable.
- v1 backups restore (six defaults created, expenses → Cash). DB upgrade keeps all data.
- versionName 1.1.0, versionCode 2, same release key.

## Review Focus

1. **Upgrade from v1.0** — v1 DB opens under v2: rows intact, `paymentMethodId` = Cash, description/notes null. Pinned in Task 1.
2. **Old backup restore** — schemaVersion 1 JSON restores with defaults + Cash. Pinned in Task 3.
3. **Swipe vs. tap and axis** — taps never swipe; diagonal drags pick the dominant axis. Pinned in Task 7.
4. **Archived method in history** — lists/exports/Month still show an archived method's name; it never appears in swipes or pickers (except as the current value of an edited expense). Pinned in Tasks 1, 2, 8.
5. **Theme contrast** — every theme/mode keeps fg-on-bg and on-accent-on-accent ≥ 4.5:1. Pinned in Task 4.
