# Gastos.io v1.3 (Android) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Android v1.3.0 with the new app icon, file backup (save/restore a JSON file), the new backup state rules, and a backup reminder on Home.

**Architecture:** File backup reuses `BackupManager`'s encode/validate/replace path. JSON in and out is split from GitHub I/O, so file and GitHub restores share one code path. Small pure objects (`BackupRules`, `BackupReminder`) hold the new rules so they can be unit-tested without UI. Icons are generated by a committed Pillow script that also writes the PWA icons.

**Tech Stack:** Kotlin, Jetpack Compose, Room, DataStore, Robolectric/JUnit (existing). Python 3 + Pillow for icons.

**Spec:** `docs/superpowers/specs/2026-10-17-gastos-pwa-design.md`, sections "Backup state rules", "File backup", "Android v1.3.0 changes". Run this plan **before** the PWA plan (`2026-10-17-gastos-pwa.md`), because Task 1 also produces the PWA icons.

## Global Constraints

- No Claude attribution in commits, files or releases (CLAUDE.md). Commit with the local git identity. No `Co-Authored-By` lines.
- Every create/update/delete confirms, except adding an expense from the numpad/widget.
- versionName `1.3.0`, versionCode `4`.
- Backup JSON stays schema 2 (`BackupSerializer.CURRENT = 2`). Don't change its shape.
- Test command: `./gradlew testDebugUnitTest`. Build: `./gradlew assembleDebug`.
- Error copy for bad files reuses `BackupManager`'s DAMAGED text: "This backup file is damaged or isn't a Gastos.io backup."

## Review Focus

1. **Picking a non-JSON or huge file in Restore from file** (a photo, a PDF) → shows the DAMAGED message, and data stays as it was. Test in Task 2.
2. **Auto-backup after a file restore with no GitHub set up** → nothing happens and no error is recorded (`lastBackupError` stays null). Test in Task 2.
3. **Re-saving Settings with the same repo and an empty token field** must NOT turn backup off. Test in Task 3.
4. **Backup reminder on a brand-new install with zero expenses** → hidden. Test in Task 4.
5. **Cancelling the system file picker** (null Uri) → no dialog, no error, nothing changes. Handled in Task 3's launcher callbacks (`uri ?: return`).

  - `TILE_BOX = (84, 93, 1169, 1156)` is the dark tile in the source. Crop a **square** centered on the tile's center, with side `min(width, height)` of the box (1063).
  - `BG` = the median color of a 20×20 patch at the cropped image's center-left edge (≈ `#222322`). Print it, and write it into the color XML as `#RRGGBB`.
  - **Full-bleed square:** call `ImageDraw.floodfill(img, corner, BG, thresh=80)` on each of the 4 corners of the crop. This turns the white margin and the anti-aliased rounded corners into `BG`.
  - Android foreground: a transparent canvas of 108dp × density (mdpi 108, hdpi 162, xhdpi 216, xxhdpi 324, xxxhdpi 432). Paste the full-bleed square resized to `FG_SCALE = 0.80` of the canvas, centered. The wallet then sits inside the 66dp safe zone, and the square's edges blend into the same-colored background.
  - PWA: full-bleed square at 180, 192, 512 and 32. Maskable 512 = a `BG` canvas with the full-bleed square scaled to 80%, centered.
  - Use `Image.LANCZOS` for every resize. Save PNGs with `optimize=True`.

Open `web/public/icons/icon-512.png` and `app/src/main/res/mipmap-xxxhdpi/ic_launcher_foreground.png` (Read tool) and check by eye: there should be no white corners, and the wallet should be centered.

### Task 2: BackupManager: JSON in/out and quiet skip without credentials

**Files:**
- Modify: `app/src/main/java/io/gastos/app/backup/BackupManager.kt`
- Test: `app/src/test/java/io/gastos/app/backup/BackupManagerTest.kt` (extend the existing class and its fakes)

**Interfaces:**
- Produces (on `BackupManager`):
  - `suspend fun exportJson(): String`: encodes all data like `backupNow` does, with no network and no prefs changes.
  - `suspend fun preview(json: String): Result<BackupPreview>`: decodes and validates without writing. `data class BackupPreview(val expenseCount: Int, val exportedAt: java.time.Instant)` goes in `BackupModels.kt`.
  - `suspend fun restoreFromJson(json: String): Result<Unit>`: decode → validate → `db.replaceAll` → `setBackupEnabled(true)` → `setLastBackupError(null)` → `onDataChanged()`. Same mutex.
  - `restore()` keeps its signature. It downloads, then delegates to the same private restore-from-text function (unlocked variant) inside its own lock.
  - `backupNow()`: when enabled but the repo is blank or the token is missing, return `Result.success(Unit)` **without** recording an error and without network calls. A manual "Back up now" is only enabled when both are set, so a silent skip is safe.

- [ ] **Step 1: Write the failing tests** in `BackupManagerTest`:
  - `exportJson_roundTripsThroughRestoreFromJson`: seed 2 expenses, `json = exportJson()`, wipe (restore an empty-expenses JSON), `restoreFromJson(json)`. Assert 2 expenses come back with the same ids and amounts, `backupEnabled` is true and `dataChangedCalls` went up.
  - `restoreFromJson_garbage_leavesDataAndReturnsDamaged`: input `"\u0089PNG..."` and `"{}"`. Both fail with message `"This backup file is damaged or isn't a Gastos.io backup."`, and the existing expenses are unchanged.
  - `restoreFromJson_newerSchema_refused`: `{"schemaVersion":3,...}` fails with the "newer version" message (`UnsupportedBackupException` text).
  - `preview_reportsCountAndExportedAt`: preview of `exportJson()` gives `expenseCount == 2` and `exportedAt == clock.instant()`.
  - `backupNow_enabledWithoutRepo_isSilentSuccess`: `setBackupEnabled(true)`, no repo. Result is success, `github.calls` is empty and `lastBackupError` is null.
- [ ] **Step 2: Run.** `./gradlew testDebugUnitTest --tests "io.gastos.app.backup.BackupManagerTest"`. Expected: the new tests FAIL (unresolved references).
- [ ] **Step 3: Implement** as described in Interfaces. Wrap the non-serialization decode exceptions (`IllegalArgumentException`) from decode as `BackupException(DAMAGED)` too.
- [ ] **Step 4: Run** the same command. Expected: all PASS, including the old tests.
