# Gastos.io v1.1 — Design

Date: 2026-10-16
Builds on: `docs/superpowers/specs/2026-10-16-expenses-tracker-design.md` (v1.0, shipped as release v1.0.0). Everything there still holds unless changed here.
Mockups (approved): https://claude.ai/artifact/PdEAtjcQKDc1wNkXee5gP1

## Intent

Make logging faster and richer without slowing the one-tap entry: pick a label by swiping instead of a dropdown, optionally say what you bought, add notes later, and pick a comfortable color theme.

## Goals

1. Optional "What did you buy?" description on Home.
2. Named color themes, each with light and dark.
3. Notes on an expense, edited in Edit expense.
4. "About the dev" section at the bottom of Settings.
5. Swipe left/right on Home to change label; the screen tints to the label's color.

## Non-goals

- Description or notes on the widget (widgets have no keyboard).
- Themes on the widget (widget keeps its current always-dark look). *(Claude's call)*
- Search/filter by description.
- A manual light/dark override; light/dark keeps following the phone.

## Anti-goals

- Anything that makes adding an expense slower than today. Description stays optional; Enter still needs only an amount.
- Swipe gestures that fire by accident while tapping the numpad or text box.
- Breaking restore of existing v1.0 backups, or losing existing data on upgrade.

## 1. Home screen

Layout top to bottom (see mockup screen 1):
- Header unchanged: date, today's total, list button, overflow menu.
- **Swipe area** (the middle area, between header and text box): label name (uppercase, with faint ‹ › hints), big amount, and page dots (one per label, current one highlighted).
- **Text box** with placeholder "What did you buy?".
- Numpad and Enter unchanged.

Behavior (decided by owner):
- Swiping left/right anywhere in the swipe area changes the label. Order = the Labels screen order. **Wraps around** both ways.
- The whole screen background tints to the current label's color, with the label's name shown. Tint is a blend of the label color over the theme background (about 20% in light, 26% in dark, per mockup), animated briefly. *(blend amounts: Claude's call)*
- The label dropdown chip is removed.
- Starts on the last-used label (shared with the widget, as in v1.0). Swiping updates last-used.
- Amount, swipe, and description can happen in any order. Only the amount is required.
- Tapping outside the text box hides the keyboard (and clears its focus). The numpad keys count as "outside".
- Enter saves amount + current label + description (trimmed; empty → none), clears amount and description, keeps the label. No confirm popup (unchanged rule).
- Toast: "Added ₱45.50 · Jollibee" when there's a description, else "Added ₱45.50 · Food" (as today).

Calls *(Claude's)*:
- Horizontal swipe needs a clear horizontal drag (threshold ~ 48dp, and more horizontal than vertical) so taps never trigger it. A light haptic tick on each label change.
- Description max 60 characters; single line; keyboard "Done" closes it.
- Accessibility: the swipe area also responds to left/right actions (custom accessibility actions "Previous label" / "Next label").

## 2. Description and notes (data)

- New optional fields on an expense: `description` (≤ 60 chars) and `notes` (≤ 1000 chars). Both nullable; blank saves as null. *(limits: Claude's call)*
- Room migration v1 → v2 adds both columns. Existing rows keep null. No data loss on upgrade (migration test required).
- Lists (Today, day view): if a description exists it's the row title and the subtitle is "Label · time"; otherwise the row is unchanged (label title, time subtitle).
- Notes are not shown in lists; only in Edit expense.

## 3. Edit expense

- Adds a "What did you buy?" field (same 60-char limit) and a large multi-line "Notes" box with placeholder "Add notes…".
- Save and Delete keep their confirm popups. The save confirm text stays "Save changes to ₱45.50 · Transpo?".

## 4. Export

- Columns become: Date, Time, Label, Description, Amount, Notes (owner: both description and notes). *(column order: Claude's call — Amount stays next to the text so the SUM column is D→E; Notes last since it's long)*
- CSV: same escaping rules as v1.0 (notes may contain commas, quotes, newlines).
- XLSX: total row SUMs the Amount column (now column E); Notes column width capped (e.g. 40) with wrap text. "By label" sheet unchanged.

## 5. Backup

- Backup JSON gets `description` and `notes` on each expense; schema version → 2.
- Restoring a v1 backup still works (missing fields = null). Restoring a newer-than-supported version is still refused with the existing message.

## 6. Themes (decided by owner: named themes, each with light + dark)
